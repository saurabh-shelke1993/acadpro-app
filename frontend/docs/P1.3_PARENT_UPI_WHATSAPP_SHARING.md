# P1.3 — Parent Portal UPI QR and WhatsApp Sharing

**Status:** Implemented; CI validation pending  
**Branch:** `payment-module-finalization`  
**Scope:** Display enabled academy UPI payment details in Parent Portal and share them using a user-initiated WhatsApp link.

## Behavior

- The Parent Portal shows UPI payment details for the currently selected child only.
- The existing Parent Financial Overview continues to show the same payment details.
- The component queries `academy_payment_settings` for the selected child's academy; database RLS remains the authorization boundary.
- Disabled settings are not rendered.
- Payee name, UPI ID (when configured), and public QR image are shown.
- A WhatsApp share link opens `https://wa.me/?text=...` with a prefilled message containing the academy name, payee name, configured UPI ID, and QR image URL when available.
- QR-only configuration is supported; no UPI ID is fabricated.
- The share message explicitly says the academy must verify and record the payment before the fee balance changes.
- Sharing is user-initiated. No message is sent automatically, no phone number is collected, and no WhatsApp Business API is used.
- No database, Storage, payment-ledger or RLS changes are part of P1.3.

## Automated tests

Component tests cover:
- Enabled settings render for the selected academy.
- QR image URL and UPI ID appear in the WhatsApp share message when configured.
- QR-only settings omit the UPI ID.
- Disabled settings are hidden.
- No settings query occurs when no academy is selected.

## Browser acceptance

1. Sign in as a Parent with a linked child whose academy has enabled UPI settings; verify QR, payee name and UPI ID.
2. Switch between linked children in Parent Portal; verify UPI details follow the selected child's academy.
3. Verify disabled settings do not appear in Parent Portal or Parent Financial Overview.
4. Select **Share payment details on WhatsApp**; verify WhatsApp opens with the correct academy, payee, UPI ID and QR URL.
5. Verify QR-only settings share the QR URL without displaying an empty UPI ID.
6. Verify the share message says the fee balance changes only after the academy verifies and records the payment.
7. Confirm no payment record or due balance changes after displaying or sharing payment details.

## Deferred

Parent UPI submission/UTR capture and the Academy Owner verification queue remain P1.4. Transactional confirmation using the existing payments ledger remains P1.5. Razorpay remains outside this phase.
